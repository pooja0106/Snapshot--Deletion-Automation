# Snapshot--Deletion-Automation
The objective of this project is to learn and implement PowerShell scripting to automate the removal of VMware snapshots and Hyper-V checkpoints after successful Windows OS in-place upgrades.

#Project Objectives

Retrieve VMware VM snapshots.

Retrieve Hyper-V VM checkpoints.

Identify snapshots and checkpoints older than 74 hours.

Validate OS upgrade status before cleanup.

Automate approved snapshot and checkpoint removal.

Generate execution logs and reports.
